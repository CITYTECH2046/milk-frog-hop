# 奶蛙跳一跳

手机浏览器小游戏：按住蓄力，松手跳跃。使用提供的黄色奶蛙形象，无笑声。

## 操作

- 手机：按住画面或下方按钮，松手起跳。
- 电脑：按住空格键或鼠标，松开起跳。
- 普通落地加 1 分，连续落在中心获得 2、4、6、8、10 分，之后每次中心落点最高加 10 分。
- 最高分保存在当前浏览器本地。
- 普通音效默认关闭，可点击右上角音量按钮开启。

## 发布到 GitHub Pages

1. 在 GitHub 新建公开仓库，例如 `milk-frog-hop`。
2. 把此文件夹中的 `index.html`、`style.css`、`game.js`、`frog.png` 和 `.nojekyll` 上传到仓库根目录。不要只上传 ZIP 文件。
3. 进入仓库 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. 选择 **main** 分支和 **/(root)**，点击 **Save**。
6. 等 GitHub 显示发布成功，使用 Pages 设置页给出的游戏链接。微信中分享游戏链接，不是仓库地址。

不需要安装依赖、运行构建或连接 ChatGPT。游戏没有外部字体、脚本或图片依赖。

GitHub Pages 的可访问性需要在目标手机和网络环境中实测。本项目不保证所有地区和微信环境均可访问。
